# 产品方案

## 1. 一句话定位

给"说不清自己该怎么学"的学生，用一次对话换一份**能听的周计划**：方案由 AI 按个人情况拆解，课程做成音频，走路、通勤、睡前都能完成一次学习。

## 2. 为什么是音频课

- 学生真正缺的不是资料，是**在正确的时间听正确的内容**。音频把"必须坐到书桌前"的门槛降到"戴上耳机"。
- 音频天然适合"一次 15–25 分钟"的节奏，和 0.8 元/分钟的价格锚点匹配（一节 20 分钟 ≈ 16 元）。
- 生产成本可控：一节 800 字讲稿 + TTS，不需要老师出镜、不需要剪辑。
- 副作用：完课率、复听率、单节时长都能被精确计量，而计量正是计费基础。

## 3. 用户与场景

| 角色 | 谁付费 | 核心诉求 | 关键动作 |
| --- | --- | --- | --- |
| 学生（初高中为主） | 家长 | 知道每天该学什么、怎么补薄弱点 | 对话 → 听课 → 复述作业 |
| 家长 | 是 | 看得见进度、钱花得明白 | 看方案、看账单、看报告 |
| 邀请人（老用户/家长群主） | 否 | 推荐有回报 | 发邀请码 → 看佣金 |

## 4. 主流程（也是小程序的 5 个页面）

```
① 登录（微信静默登录，可填邀请码）
      ↓
② 对话诊断：小习提问 → 抽取年级/科目/薄弱点/时间 → 写入长期记忆
      ↓
③ 生成方案：N 周 · 每周 M 节 · 每节 K 分钟（可改）
      ↓
④ 听课：生成本周课程 → 点开 → 播放音频 → 计时计费 → 暂停即结算
      ↓
⑤ 会员与推荐：余额、账单、记忆管理、邀请码、佣金
```

每一步都有明确的"下一步按钮"，不存在需要用户自己找入口的分支。

## 5. 功能清单与优先级

**P0（已实现）**
- 微信登录 + 邀请码绑定（一次性，不可改）
- 多轮对话，每轮抽取向导（不打断对话）
- 长期记忆：结构化事实 + 置信度 + 可删除
- 方案生成：周里程碑 + 交付物 + 专题
- 周课程生成 → 讲稿 → 音频（可降级文本）
- 听课计时：体验额度优先，之后按 0.8 元/分钟
- 钱包：充值、消费流水、佣金余额
- 推荐分佣：会员累计消费满 50 元才计入序号，每 3 个达标会员一轮，20% / 50% / 70% 循环（只算直推，单笔封顶 100%）
- 佣金 T+7 结算、提现申请

**P1（上线前建议补）**
- 微信支付（下单 + 回调 + 幂等 + 退款）
- 支付前协议勾选与自动续费/预付费规则说明
- 内容安全：讲稿过审（文本 + 音频）、敏感词、AI 生成标识
- 家长绑定与周报（家长是付费人，必须有专属视图）
- 学习报告：每周完成度、复述录音评分（可选）

**P2（增长）**
- 邀请海报、班级/家长群场景
- 课程复听不计费或半价（提升留存）
- 套餐：月卡 N 分钟包，比按分钟更便宜，改善现金流

## 6. 定价与单位经济

- 会员 0.8 元/分钟 = 48 元/小时，一节 20 分钟 ≈ 16 元。
- 体验 60 分钟 ≈ 送 48 元价值，对应获客成本（CAC）上限约 48 元，需要用它换到至少 1 个付费用户才算打平。
- 每 3 个达标会员为一组，佣金合计是"一个人消费额"的 140%，平均到每人约 46.7%，平台平均留存 53.3%。三个档位都有正毛利（20% 档 +67%、50% 档 +37%、70% 档 +17%）。"消费满 50 元才计入序号"把"注册小号占位"的成本抬到 50 元以上（详见《计费与佣金》与《合规风险与整改建议》）。

## 7. 关键指标（埋点建议）

| 指标 | 定义 | 目标方向 |
| --- | --- | --- |
| 方案生成率 | 登录后 1 小时内生成方案的比例 | > 60% |
| 首课收听率 | 方案生成后 24 小时内开课 | > 50% |
| 体验耗尽率 | 60 分钟体验用尽的比例 | 观察项，过高说明内容抓人但付费转化没接上 |
| 付费转化率 | 体验耗尽 → 开通会员 | > 25% |
| 单课完课率 | 播放时长 / 课程总时长 > 80% | > 55% |
| 复听率 | 7 日内二次开课 | > 40% |
| 人均月消费 | 元/月 | 先看分布，再定价 |
| 邀请系数 K | 每位付费用户带来的新付费用户 | 与佣金比例联动，但别越过合规线 |

## 8. 内容原则（写进系统提示词，也写进运营 SOP）

1. 不承诺提分、不承诺名次，不做诊断式断言（已写进 `llm.js` 的 `CHAT_RULES`）。
2. 一节课只讲一个结论，末尾必须留 3 分钟能做完的作业。
3. 讲稿为"听"而写：短句、口语、公式读法化、关键结论重复一次。
4. 面向未成年人：不收集与学习无关的信息，不做排名羞辱，不使用焦虑营销话术。

## 9. 不做的事

- 不做直播课、不做真人老师撮合（监管与成本都重）。
- 不做题库/拍照搜题（版权与合规成本高，且与"音频"定位冲突）。
- 不在体验期就要求绑定手机号/付费；先让用户听到价值。

## 10. 下一步建议（两周内）

1. 找 10 个真实学生跑一遍对话 → 看方案是否"像人排的"（当前离线 Mock 只能演示流程，必须接真实 DeepSeek Key 验证质量）。
2. 用真实 TTS 替换本机 SAPI，测一节 20 分钟音频的合成成本与音质。
3. 先只上线"固定 20% 的一级推荐"，把 20/50/100 循环方案留作活动配置，观察 30 天数据与审核结果。
